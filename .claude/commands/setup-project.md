---
description: Workflow for setting up the project
---

Follow the workflow below.

1. Step 1. Read the ideas:
- Check whether `/docs/ideas/initital-idea.md` exists
- Confirm it exists before moving on to the next step

2. Step 2. Create the RPD:
- Based on the ideas, create the following files and save them in `/docs/spec/`:
**product-requirements.md**
**functional-design.md**
**architecture.md**
**repository-structure.md**
**development-guidelines.md**
**glossary.md**

3. Step 3. Run the /review-doc with sub-agent.

4. Step 4. Ask for review confirmation.

5. Step 5. /add-feature
